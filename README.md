# STM32F407 + ST7789V LCD 图片播放器

基于 STM32F407VET6 驱动 240x240 ST7789V 液晶屏，从 W25Q64FV Flash 读取并显示图片，支持双缓冲、CCM 内存优化、智能图片管理

---

## 项目简介
这是一个轻量级的嵌入式图片播放器项目，核心特性：
- 🚀 **双缓冲乒乓操作**：Flash 读取与 SPI 发送并行，最大化刷新效率
- ⚡ **CCM 内存支持**：利用 STM32F407 64KB 零等待 CCM 内存，提升数据处理速度
- 📸 **智能图片管理**：仅需修改一个宏定义即可适配任意张数图片，自动计算 Flash 地址
- 🔄 **自适应按键循环**：按键自动在图片间循环切换，无需修改代码

## 软件特性
1.  **双缓冲乒乓操作**：使用两个行缓冲区，SPI 发送当前行的同时读取下一行，消除串行等待
2.  **CCM 内存支持**：可将缓冲区放入 STM32F407 的 64KB CCM 内存（0x10000000），零等待周期
3.  **智能图片地址计算**：`地址 = 图片索引 × 单张图片大小`，自动适配任意张数
4.  **自适应按键循环**：使用取模运算 `(index + 1) % TOTAL_IMAGES`，自动循环不越界

## 快速开始

### 1. 图片及flash准备
- 图片格式：240x240 RGB565（16位色）
- 文件大小：单张图片必须为 **115200 字节**的bin文件（240×240×2）
1. 将所有 `图片.bin` 图片放入同一文件夹
2. 合并为一个BIN文件
3. 将该bin文件烧录进Flash中
### 2. 程序修改
仅需修改 `main.c` 中的一个宏定义：
```c
#define TOTAL_IMAGES  2  // 👈 改成你实际的图片张数
```

### 5. 烧录与运行
1. 将程序烧录到 STM32F407
2. 上电自动显示第 0 张图，按 PE0 按键切换下一张

## 常见问题

### Q: 屏幕花屏怎么办？
A: 请检查：
1. SPI 时钟是否过高（建议先降到 8 分频）
2. 杜邦线是否过长（建议 ≤20cm，最好绞合接地）
3. 图片格式是否正确（RGB565、240x240、115200 字节）
4. 图片字节序是否匹配（可尝试取消/添加 `__REV16` 转换）

### Q: 屏幕不显示只有背光？
A: 请检查：
1. LCD 初始化序列是否完整
2. 引脚连接是否正确（特别是 CS、RS、RST）
3. 供电是否稳定（3.3V，共地良好）
