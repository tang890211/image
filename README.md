# STM32音图多媒体交互终端

本项目是一个基于 STM32F4 系列微控制器的多媒体交互系统。集成了 SPI 外部 Flash 图像解码、DMA 硬件加速彩屏驱动、I2C OLED 实时状态监控以及基于 UART 的 MP3 音乐控制功能。

系统具备独特的**双工作模式（普通模式/安全模式）**，通过独立按键进行平滑切换，适合作为嵌入式 GUI 学习、桌面摆件或交互式硬件开发的参考模板。

## ✨ 核心特性 / Features
*   **硬件加速的图像渲染**：采用 `SPI + DMA` 双缓冲机制（Ping-Pong Buffer），从 W25QXX 外部 Flash 高速读取 240x240 RGB565 图像并推送到 LCD 彩屏，极大降低 CPU 占用。
*   **多行状态监视器**：利用 0.96寸 OLED 屏幕作为状态副屏，实时显示系统当前工作模式、图片索引（支持多张轮播）、音乐播放/暂停状态。
*   **UART 异步音频控制**：集成 CX1000AM 串口 MP3 模块协议，支持完整的播放、暂停、停止指令集。
*   **安全模式 (Safe Mode)**：一键触发安全模式。触发后立即强制停止音乐播放，限制图片浏览范围（仅限前 2 张安全图像）避免外人查看个人隐私图片。

## 🛠️ 硬件依赖与引脚映射

### 1. 核心与外设
*   **主控**：STM32F407VET6
*   **主屏(显示屏)**：JLX130-026-PC液晶模块
*   **副屏(控制屏、信息屏)**：0.96寸 I2C OLED (SSD1315)
*   **存储**：W25Q64 Flash
*   **音频**：MP3 解码播放模块CX1000AM、最高5W喇叭

## 💻 开发与编译环境

*   **IDE**：Keil uVision 5
*   **编译器**：ARM Clang V6.24 (Compiler V6)
*   **底层库**：STM32 HAL 库 (通过 STM32CubeMX 生成代码框架)

## 🚀 快速上手

1.  **图片数据烧录**：
    在运行代码前，需提前将 n 张(默认8张，如果比这多需要自己取多出来的数字字模并且修改对应显示的程序和`#define TOTAL_IMAGES  2 `函数；少的只需修改函数)图片分辨率为240x240RGB565格式图片的数据 `.bin` 文件烧录至 W25QXX Flash 的 `0x000000` 连续地址中。
2 **操作说明**：
    *   开机默认进入**普通模式**，LCD 显示第 1 张图片，OLED 显示就绪状态。
    *   按下 `PE2` 开启音乐，OLED 图标会实时反馈“播放中”状态。
    *   按下 `PE0` / `PE1` 循环切换 8 张图片。
    *   遇到突发情况，按下 `PE3` 进入**安全模式**，音乐瞬间静音，画面切回首张。此时除非复位，否则只能看**前2张**
